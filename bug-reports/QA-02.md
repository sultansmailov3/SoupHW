# QA-02 — Default training install hits a PEFT/torchao conflict on Colab T4

**Environment.** Soup CLI 0.77.2, default Google Colab Python 3 GPU image, Tesla T4. See `logs/gpu.log` and `logs/freeze.log` for versions.

**Steps.** Install `soup-cli[train]==0.77.2` on a fresh Colab T4 runtime and run `python repeat.py`. The local tiny GPT-2 control uses LoRA and `training.quantization: none`.

**Expected.** The documented installation supports the basic training case in the specified environment.

**Actual.** All three initial training calls exited 1 during setup. The CLI diagnosed that installed PEFT refuses Colab's preinstalled torchao. The log gives an actionable workaround. The original raw stderr and configs are retained in the first `logs/training-*/` directory.

**Severity.** Medium, setup compatibility. The failure is explicit and can be worked around. The test did not attribute the dependency incompatibility solely to Soup.
